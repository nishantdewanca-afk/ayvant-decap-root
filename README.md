# ayvant.ca

The website for Ayvant IT & Cybersecurity Inc. (Langley and Surrey, BC), deployed by Netlify from `main`.

- **Learning Hub:** write and edit posts at **ayvant.ca/admin**. Posts are saved to `content/ca/blog/`, images to `site/public/images/uploads/`. A post with a future date goes live on the first build that day.
- **Build locally:** `cd site && npm install && NEXT_PUBLIC_SITE=ca npm run build` (output in `site/out`).
